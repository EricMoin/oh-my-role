# Color composition

## Establish the source and direction

For an existing product, inspect its theme or component tokens alongside a representative screen. Learn which surfaces belong together, how selection reads, and where brand and status colors appear. If the theme and screen disagree, trace the component or compare a sibling use before adopting the exception. A screenshot can establish an observed convention when token names are unavailable. For a refinement, carry these relationships forward. A request for more breathing room can often be fulfilled with spacing and type while retaining the existing palette.

For a new product or an authorized change of direction, start from an available brand color, image, material or content cue. Choose a base for the largest field. Place the neighboring panel and text against it, adjusting their undertones and lightness until the intended layers are visible. Introduce action and status colors on those surfaces. Name the resulting foreground/background pairs by use so components can share them.

In the Design State's Direction, record the source, the regions that should read as one space, what should stand out and when that emphasis should change. For example, an archive inspector might keep the list and record in one workspace and give an incomplete recovery precedence over routine metadata.

## Compose on a representative screen

1. Inspect the canvas, navigation, panels and prominent imagery side by side at their actual sizes. Look at undertones, relative lightness and chroma. Two nominal whites can make each other look yellow or blue where their edges meet. Adjust one if both areas are meant to read as the same material. A cool navigation area against a warm reading surface can deliberately mark a change of context.
2. Apply action, selection, status and data colors to real content. Trace consequential fills to the project's semantic roles or name a new role and its reason. Check the selected, unselected and feedback states the task actually has. A tint on one label may dominate when repeated down a list. Prefer correcting an assignment or its area first. If a shared primitive needs to change, inspect its other consumers, themes and states.
3. Inspect this composition before extending it across screens. If a broad palette decision is unsettled, compare plausible treatments with the same content, layout, viewport, theme and state. Choose the treatment that best serves the direction. A local correction can be judged directly against its baseline. Across a reusable system, check another representative use where density or state changes the balance.

## Read the result

On the current render, describe which regions appear to belong together, where your eye lands, and what looks selected or urgent. Compare that observation with the direction, the system source and the actual state. Name the two elements and the visible consequence when filing a finding. Preserve deliberate warm/cool contrast, vivid brand surfaces and distinct data series when they serve the design. Hue count and colored-area percentages have no universal pass threshold.

| Observation | Judgment |
| --- | --- |
| In one reading area, a near-black green rail, cream canvas, white panels and a mint summary each look like a separate destination. The baseline groups the list with the current record. | Compare the rail's lightness against the canvas and the panel's undertone against the summary. Retune the boundary that breaks the intended grouping. Preserve a pronounced boundary where it deliberately separates tools from content. |
| An empty detail pane says nothing is selected, while a list row has the same inverted fill as the selected row in the detail view. | The color communicates a false selection. Restore the default row treatment in the empty state and compare the two frames. |
| A warning summary and every supporting row use the same full-width amber fill. The conclusion disappears among the details. | Keep the summary identifiable. Try a quieter treatment for supporting rows and retain their status labels or icons. |
| A bright categorical chart occupies most of the screen. Each series keeps its documented color and remains distinguishable against the plot surface. | The large color area supports the comparison. Preserve it. |

Record foreground/background contrast separately for the pairs actually measured. When only a written specification is available, assess the proposed roles and pairings and identify which composition judgments still need a render.
