Selected effort: {level}. If no value was supplied, use medium.

Effort changes analysis depth and overhead, never tool permissions or authorization.
High effort permits more research and independent review when uncertainty warrants
it. Medium effort follows normal triage. Low effort favors a single executor with
scoped checks for clear changes. Neither
setting converts implementation into a DIRECT answer or bypasses a pending gate.
Plan mode still requires a reviewable strategy and approval before execution.
